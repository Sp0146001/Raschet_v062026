# Raschet_v062026

`Raschet` — настольное приложение на **Python + PySide6 + pyqtgraph** для:

- загрузки и визуализации многоканальных измерений сенсоров;
- выделения участков сигнала;
- расчёта откликов и констант по выбранному диапазону;
- сохранения сегментов в **SQLite-проект**;
- предобработки сегментов;
- расчёта признаков;
- первичной аналитики через **PCA**.

Проект развивается как современная замена и расширение старых исследовательских инструментов для сенсорных данных.

---

## Что уже реализовано

### 1. Измерения и расчёт
- загрузка TXT-файлов с несколькими шаблонами заголовка;
- разбиение данных по каналам Time/Resistance;
- построение графиков по всем каналам;
- скрытие/показ каналов галочками;
- переименование каналов;
- логарифмический / линейный режим по оси `Y`;
- bar-line по времени `tᵢ`;
- таблица значений `Rᵢ`;
- выделение участка мышью или вручную;
- расчёты:
  - `Отклик-Сопр.Растёт`
  - `Отклик-Сопр.Падает`
  - `Восстановл-Сопр.Падает`
  - `Восстановл-Сопр.Растёт`
- поиск `t(0.9)` / `t(0.1)` с линейной интерполяцией;
- усреднение по `N` точкам;
- экспорт графика, результатов и участка.

### 2. Работа с БД проекта
- создание проекта SQLite;
- открытие существующего проекта;
- импорт исходных TXT-файлов в проект;
- хранение исходных файлов, каналов и точек в БД;
- сохранение выделенных сегментов в БД;
- просмотр списка сегментов;
- повторное открытие сегмента на графике;
- возврат от сегмента к исходному файлу.

### 3. Разметка сегментов
Для выделенного участка можно сохранить:
- название сегмента;
- газ;
- концентрацию;
- температуру;
- свет (`ON/OFF`);
- комментарий.

### 4. Предобработка
Реализованы профили предобработки с сохранением в БД.

Поддержанные операции:
- `log(x)`
- `x/Xref`
- `Xref/x`
- `x/median(x)`
- `(x-mean(x))/std(x)`

Также можно:
- выбрать референсный сегмент;
- применить профиль к выбранному сегменту;
- сохранить результат предобработки в БД;
- открыть результат предобработки на основном графике.

### 5. Признаки
Для сегмента или результата предобработки считаются признаки по каждому каналу:
- `t_start`
- `t_end`
- `duration`
- `r_start`
- `r_end`
- `delta_r`
- `mean_r`
- `median_r`
- `std_r`
- `min_r`
- `max_r`
- `amplitude`
- `auc`
- `slope`
- `rms`
- `abs_diff_sum`
- `q10`
- `q90`

Признаки можно сохранить в БД как отдельный набор.

### 6. Аналитика
Сейчас реализован первый шаг аналитики — **PCA**:
- выбор наборов признаков из БД;
- фильтрация по источнику / газу / температуре / свету;
- выбор режима масштабирования;
- таблица дисперсий;
- таблица scores;
- таблица loadings;
- 2D график `PC1 / PC2`.

## Установка зависимостей

### Рабочее окружение
```powershell
py -3.13 -m venv .venv
Set-ExecutionPolicy -Scope Process Bypass
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### Облегчённое окружение для сборки
```powershell
py -3.13 -m venv .venv_build
Set-ExecutionPolicy -Scope Process Bypass
.venv_build\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements_build_lite.txt
```
